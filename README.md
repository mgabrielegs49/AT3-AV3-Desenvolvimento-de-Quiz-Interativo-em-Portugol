2 TEMA DO PROJETO
O projeto consiste em um quiz sobre "Variáveis na Programação", contendo
perguntas de múltipla escolha focadas em tipos de dados, regras de nomenclatura e
armazenamento de memória para testar os conhecimentos fundamentais dos
usuários.

3 OBJETIVO DO SISTEMA
O objetivo do sistema é proporcionar uma experiência interativa por meio de
um jogo de perguntas e respostas, revisando e consolidando os conceitos de
Algoritmo e Lógica de Programação, especificamente no uso de variáveis.

4 FUNCIONALIDADES
 Menu principal com navegação interativa;
 Iniciar jogo com validação de respostas independentes do uso de letras
maiúsculas ou minúsculas;
 Visualizar regras do jogo;
 Responder a perguntas de múltipla escolha (A, B, C, D);
 Sistema de pontuação contabilizando acertos, erros e pontos totais;
 Encerrar programa de forma segura.

5 ESTRUTURAS UTILIZADAS
5.1 Variáveis
Utilizadas para armazenar a opção do menu (inteiro), a resposta do usuário
(caracter) e os contadores de pontuação, acertos e erros (inteiro).
5.2 Estruturas de Decisão
 se / senao: Utilizados para verificar se a resposta digitada pelo usuário está
correta ou incorreta, atualizando a pontuação.
 escolha caso: Utilizado para gerenciar a navegação do Menu Principal (casos
1, 2, 3 e caso contrario).
5.3 Estruturas de Repetição
enquanto: Utilizado para manter o programa em execução contínua até que a
opção de saída (3) seja acionada pelo usuário.

6 FLUXO DO SISTEMA
1. O usuário acessa o menu principal.
2. Escolhe iniciar o quiz ou visualizar as regras ou sair.
3. Se escolhe sair, o sistema encerra e se despede.
4. Se escolhe visualizar as regras, o sistema mostra as regras.
5. Se escolhe iniciar o quiz, durante o quiz, responde às perguntas digitando a
alternativa desejada.
6. O sistema verifica as respostas a cada entrada usando condições lógicas.
7. A pontuação, os acertos e os erros são calculados em tempo real.
8. Ao final das perguntas, o resultado detalhado é apresentado e o usuário
retorna ao menu.

8 Considerações Finais
Durante o desenvolvimento, foram aplicados de forma prática os conceitos de
variáveis, estruturas de decisão (escolha caso, se/senao) e repetição (enquanto). A
principal dificuldade contornada foi a criação do fluxo lógico para garantir que as
variáveis de pontuação fossem zeradas adequadamente sempre que um novo jogo
fosse iniciado no menu. O projeto contribuiu ativamente para o desenvolvimento do
raciocínio lógico, controle de laços e organização estrutural do código.
